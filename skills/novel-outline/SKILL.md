# 小说大纲（Outline：总纲 / 分卷 / 章纲）

把"按什么顺序写"落成三级大纲，并**调度**前几层的产出（金手指爽点、台阶突破、主角弧线）进具体章节。属于**开工准备包第 ④ 层**，依赖 ①②③（全景见 `docs/notes/2026-06-01-小说开工准备包全景.md`）。

**核心设计：框架与剧情分离。** `template.md` 三级 schema 稳定；每本书填一份命名实例（`docs/outlines/<作品名>.md`）。

**语言：** 跟随用户，默认中文。

## 两种模式

| 模式 | 干什么 | 触发 |
|---|---|---|
| **建大纲**（默认） | 自顶向下产出总纲→分卷→章纲 | "列大纲""排分卷""写章纲" |
| **校验**（可选） | 查四件套/开局漩涡/突破节奏 | "大纲节奏对吗" |

> 前置：建大纲前最好已有 ①②③⑤ 的实例。缺哪块就先去对应 skill 补，否则大纲会悬空。

---

## 模式一 · 建大纲（自顶向下）

### Phase 1：总纲（§1）
主线一句话 + 主角弧线（**引用 ③ 角色卡 §5，不重写**）+ 主要冲突 + 前两卷爽点节奏。不必写到结局。

### Phase 2：分卷骨架（§2）
- 定卷数（3-7）。
- **每卷强制四件套**：开篇钩子 + 2-3 中段爆点 + 卷末高潮 + 下一卷悬念。缺一项就提醒补。
- 「境界跨度」用 ② 台阶做尺；「爆点类型」用 ⑤ 驱动模型（别给冷峻气质硬塞打脸爆点）。

### Phase 3：章纲（§3，按卷推进）
按三段式逐章：开头钩子 → 中段铺垫 → **章末爆点/悬念（优先级最高）**。建议先写完一整卷章纲再铺正文。

### Phase 4：开局特护（§4，重中之重）
单独过一遍前 10 万字死亡漩涡：
- 前 1000-2000 字金手指必现（接 ①）；前 3 章每章小爽点；前 10 章一次小爆点；前 1-2 万字主线展开（签约门槛）；前 10 万字第一次大高潮。
- **铁律**：前 3 章密度 > 前 30 章总和。别把铺垫堆开头。

### Phase 5：存盘
复制 `template.md` 结构填好，写入 `docs/outlines/<slug>.md`（目录不存在则创建），删模板提示块。
参考实例：`examples/fanren.md`（总纲 + 卷一 + 开局 + 章纲示例）。

---

## 模式二 · 校验（可选）

读大纲 + ①②③⑤ 实例，逐项体检：

1. **四件套**：每卷都有 开篇钩子/中段爆点/卷末高潮/下卷悬念 吗？
2. **章末钩子**：章纲的章末是爆点或悬念，还是平淡收束？
3. **开局漩涡**：五道关卡都达标吗？金手指在 2000 字内出现吗？前 3 章是否被铺垫拖垮？
4. **突破节奏**：境界跨度是否用 ② 台阶；升级快慢是否对齐 ⑤ 维度 C？
5. **爆点类型自洽**：爆点驱动模型是否匹配气质（冷峻别硬塞打脸）？

输出：问题清单 + 定位到卷/章 + 修补方向。辅助信号，需人工拍板。

## 文件与边界

| 文件 | 作用 |
|---|---|
| `template.md` | 大纲三级框架·稳定 schema |
| `examples/fanren.md` | 凡人式总纲+卷一实例，接口对齐上游 |
| `docs/outlines/<slug>.md` | 用户产出的大纲（每本书一份） |

**关键边界**：
- **④ 调度 / ② 定义 / ⑥ 登记**：大纲调度"何时突破/爆点"；台阶在 ② 定义；实际进度进 ⑥ 状态表。
- **④ 爆点位置 / ⑤ 爽点密度**：大纲定"第几章给"；风格契约定"多密、什么驱动模型"。

## 链路
- **上游**：①金手指 · ②台阶 · ③弧线/配角 · ⑤密度。建大纲前应先备齐。
- **下游**：章纲连同 ⑤ 风格前缀、③ 角色卡、② 设定一起，作为上下文喂给章节生成；写后进度进 ⑥ 状态表。
