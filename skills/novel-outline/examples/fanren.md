## 3. 章纲示例（卷一开篇两章）

```
第 1 章 · 七玄门
├─ 开头钩子：贫家少年韩立被选入七玄门——一条改命的窄路。
├─ 中段铺垫：门派现实残酷,资质平平者多沦为杂役;韩立暗暗观察、不出头。
└─ 章末悬念：他无意间得到一个不起眼的神秘小瓶。  ← 金手指在 1000-2000 字内出现

第 2 章 · 小瓶
├─ 开头钩子：小瓶似乎能让枯萎草木异常生长。
├─ 中段铺垫：韩立反复试探,确认小瓶能催熟灵药——但绝不声张。
└─ 章末爆点：他想清楚这意味着什么——一条别人没有的稳定资源路。  ← 小爽点,务实型
```

## 4. 开局特护（前 10 万字）

| 关卡 | 本作落点 |
|---|---|
| 前 1000-2000 字 | 第 1 章末小瓶出现 ✅（对接 ① 金手指） |
| 前 3 章 | 章章有"藏拙+小收获"的务实小爽点 |
| 前 10 章 | 第一次靠小瓶资源+谨慎,化解一场低阶杀局（危机驱动小爆点） |
| 前 1-2 万字 | 七玄门主线展开,关键同门/对头登场,冷峻基调坐实 |
| 前 10 万字 | 卷一卷末:险中筑基成功（第一次大高潮 = §2 卷一卷末高潮） |

> 注意：本作开局**不靠打脸装比**，小爽点是"被低估者悄悄占得先机"——与 fanren 风格、韩立人设一致，不强行套热血模板。
