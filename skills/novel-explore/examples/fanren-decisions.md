## 决策流水

### 2026-06-03 · 金手指 + logline

- **决策点**：靠什么爽——这本书的金手指是什么。
- **分叉轴**：机制类型 × 强度曲线（白给快爽 ↔ 有代价/成长性的慢热）。
- **候选**：
  - A：**系统签到流**——每日签到白给资源/功法。强度白给、爽点是即时奖励，开局就快。
  - B：**资源催熟（小绿瓶）**——一滴神秘液体能催熟灵药灵草，有代价（瓶子来历不明的悬念 + 灵液有限）、强成长性（随境界解锁更大用处）。慢热，爽点是苟着积累后的厚积薄发。
  - C：**无敌剑体**——开局战力碾压。强度太强，中后期没张力。
- **选中**：B（资源催熟·小绿瓶）。
- **理由**：读三版我比的是"长期张力来源"——A 即时白给（前期猛，但我看后期金手指早早封顶），C 我读着开局就碾压、想不出中后期还怎么爽；B 的张力来自**成长性 + 代价**双轴，我觉得能撑很久。且 B 跟"凡人苟道"气质我读着最搭：白给的 A、碾压的 C 都和"务实惜命、慢慢攒"冲突。
- **落盘去向**：`①concept docs/concepts/fanren.md` · 填 §1 logline（韩立 + 小绿瓶 + 凡人逆袭长生）+ §3 机制（资源催熟 / 神秘小瓶）+ §4 强度曲线（定位=适中 / 成长性=随境界解锁催熟上限 / 代价=来历不明的悬念 + 灵液消耗）。
  - **§5 龙头接口已校**：→③ 主角=务实惜命苟道（与小绿瓶"慢慢攒"自洽 ✓）→② 设定=小瓶打破"资源瓶颈"而非凭空挂载 ✓ →⑤ 维度C=升级慢需积累 ✓ →④ 节奏=厚积薄发 ✓。四项不破。

### 2026-06-03 · 文字质感（与开篇场景合流）

- **决策点**：ch1 开篇场景（韩立第一次摸到小瓶）的文字质感——读着对不对。
- **分叉轴**：句长 × 抒情度 × 视角距离。
- **候选**（同一开篇场景，各写 ~300 字一段正文）：
  - A：长句 + 高抒情 + 近距离（贴内心，情绪形容词堆满）——"他心中狂喜，激动得双手发抖……"
  - B：短句 + 冷抒情 + 中距离（白描动作，情绪演不说）——"他不动声色，把瓶子收进了怀里。"
  - C：中句 + 中抒情 + 远距离（旁白交代多）——说书腔。
- **选中**：B（冷峻苟道）。
- **理由**：读三段我比"扛不扛得住后续上千章"——A 我读着开篇情绪就用满了，往后想不出怎么递进；B 那句"不动声色地收进怀里"我觉得留了余地，和苟道气质同频。差异落在具体句子上，不靠抽象描述。
- **落盘去向**：`runtime 装配·样例锚块` · 选中的 B 段（~300 字）**顶替 ch1 默认的"参照原著片段"**。
  - **落地注意**：runtime template §2 装配单表当前没有"样例锚"行（散文块在 SKILL §装配），落地时补一行（见设计 §二 / findings F13）。
- **探针记录（#11）**：额外做了对照——另写一版按 A 风格出一稿，再口头指出"太热血"让它改一稿，对比"直接 bake-off 选 B"。
  - 观察：改写版确实把形容词改冷了，但**保留了 A 一稿的长句骨架**（改了纹理没改句式）；bake-off 直接选 B 拿到的是**短句骨架**。
  - 初步迹象：质感这种"句式骨架级"差异，改写 pass（消费审计清单逐条改）够不着，多版本选可能有它给不了的价值。**但 n=1、示意级、存疑**——"发现期多版本选 > 单版迭代"仍零硬证据，留待真连载多点量。

### 2026-06-03 · 爽点配方（阶段 2 · 双 sink 示范）

- **决策点**：小绿瓶（已定金手指）+ 冷峻苟道（已定气质）下，爽点的**兑现密度/节奏**——不是选爽点类型（"资源催熟"已锁死类型），是选多快给一次、给多重。
- **分叉轴**：兑现密度/节奏（高频小爽 ↔ 低频厚积大爆）。
- **候选**：
  - A：高频——每 3-5 章一个小打脸/小获宝，即时反馈不断。
  - B：低频厚积——苟十几章攒资源，一次性大跨越/反杀，爽点稀但重。
  - C：折中——前期高频立追读，中期转低频上强度。
- **选中**：B（低频厚积）。
- **理由**：A 的高频和"资源催熟需积累 + 苟道惜命"打架（小绿瓶白给不了即时爽）；B 的"攒够一次爆"才是这金手指的张力来源。读三版的节奏感，B 最不别扭。
- **落盘去向（双 sink · 先主后校）**：
  - **主**：`⑤style docs/styles/fanren.md` 维度 C——升级速度=慢、爽点密度=低、单元驱动=探索/危机为主。
  - **校**：`①concept docs/concepts/fanren.md` §4 强度曲线——"成长性=需积累"与"低频厚积"一致 ✓，不冲突、无需回改。
- **探针记录**：无（非质感档，不涉 #11）。
