## tick 演示（写完第 3 章后）

### 第 3 步 · 语言指纹 daemon（真跑）

```
node lab/novel-fingerprint/fingerprint.mjs 第1章.txt 第2章.txt 最新章.txt --names 专名表.txt
```

输出（示例·退出码 2 = WARN，下列读数取自开发期那 3 章劣化测试，正文未入库）：

```
[信号一] 不划算 ×3 / 来历不明 ×3 / 枕席底下 ×3 / 试练气 ×3 …
[信号二b] 章末口头禅：慢慢来(2/3章末)、别人没有、半个字都、手里、怀里
[判定] ⚠️ WARN —— 建议改写最新章：章末口头禅 + 高频词堆积
```

> 这正是当初**手工**在劣化测试里发现的"章末趋同 + 高频词"，现在 daemon **自动抓到**了。
> 主题层（"弱肉强食"被改写成"强欺弱、弱踩更弱"）daemon 抓不到 → 交第 2 步 ⑤ 审计已标注 ⚠️。
