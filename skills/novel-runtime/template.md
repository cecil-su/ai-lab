# 运行时状态 · 框架模板

> 这是**框架**（运行时状态文件的 schema），不是某本书的内容。
> 它是连载期"每章转一圈"的状态载体：索引四个 store + 看板快照 + 读者信号口。
> 用法：复制到 `docs/runtime/<作品名>.md`，开工时初始化，之后每 tick 更新。删除本提示块。

## 维护流程（每 tick）

1. 装配（填第 2 节）→ 注入 → 生成本章。
2. ⑤ 审计 → 跑味回 1。
3. 跑语言指纹 daemon → WARN 则改写。
4. LLM 抽候选（状态/名词/伏笔）→ **人工确认**入 ⑥ 三表。
5. 更新看板快照（第 3 节）→ 下一章回 1。
