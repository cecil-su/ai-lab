# Build the desktop client as a multi-channel workbench

The desktop client will be designed as a multi-channel workbench rather than a single-channel chat view. Users should be able to stay connected to multiple project channels, see unread activity, switch between conversations, and run local agent supervisors according to their channel bindings. This increases MVP UI and state-management complexity, but it matches the intended team workflow where one developer may participate in several project or review channels at the same time.
