# 自建翻墙节点 · 小白完整教程(VPS + 3X-UI + VLESS-REALITY)

> 面向零基础。跟着从上到下做,大约 **30–60 分钟**,花费 **约 $5–15/月**,最终得到一个**自己独享、滥用历史可控、抗封锁**的节点,手机电脑都能用。
>
> 创建日期:2026-06-24 ｜ 配套自检文档:`2026-06-24-vpn节点纯净度检测指南.md`

---

## 0. 先搞懂整个流程(一张图看懂)

```
①租一台境外服务器(VPS)   →  你在国外有了一台电脑
②SSH 远程登录这台服务器     →  你能给它敲命令
③一条命令装 3X-UI 面板      →  服务器上有了图形管理后台
④浏览器打开面板,点几下      →  生成一个 VLESS+REALITY 节点
⑤复制节点链接到客户端       →  手机/电脑导入,开关一开就能翻墙
⑥用 IPPure 自检纯净度        →  确认风险、泄露、速度和解锁情况
```

> **名词扫盲**
> - **VPS**:租来的一台远程 Linux 电脑,在国外,有公网 IP。
> - **SSH**:一种远程登录方式,你在自己电脑敲命令,实际在 VPS 上执行。
> - **3X-UI**:装在 VPS 上的网页管理后台,让你不用敲复杂命令也能配节点。
> - **VLESS+REALITY**:一种**抗封锁最强**的代理协议,伪装成正常访问大网站的流量。
> - **客户端**:你手机/电脑上装的翻墙 App。
>
> **预期边界**
> - 自建 VPS 通常是**机房 IP**。它的优势是独享、可换 IP、滥用历史可控,但不等于住宅 IP,也不保证能解锁所有流媒体 / AI / 金融风控服务。
> - 本教程只用于个人学习、访问境外技术资料与科研。使用时遵守所在地法律法规。

## 1. 第一步:租一台境外 VPS

### 1.1 选服务商(挑一个)

| 服务商 | 特点 | 适合 |
|--------|------|------|
| **Vultr** | 支持支付宝/信用卡,按小时计费,机房多 | 新手首选,可随时删机换 IP |
| **搬瓦工 BandwagonHost** | 老牌,有 CN2 GIA 优质回国线路 | 想要稳的中文用户多 |
| **DigitalOcean / Hetzner / AWS Lightsail** | 大厂,稳定 | 有信用卡、英文不怵 |

下面以 **Vultr** 为例(流程都大同小异)。

### 1.2 注册并充值
1. 打开 `https://www.vultr.com/`,注册账号(邮箱即可)。
2. 进入后台,**Billing(账单)→ 充值**,支持**支付宝**,先充 $10。

### 1.3 部署服务器(Deploy)
1. 点右上角 **Deploy +** → **Deploy New Server**。
2. **Server type(类型)**:选 `Cloud Compute - Shared CPU`(最便宜,够用)。
3. **Location(机房)**:选 **Tokyo(东京)/ Seoul(首尔)/ Singapore(新加坡)**——离中国近、延迟低。
4. **Image(系统)**:选 **Debian 12** 或 **Ubuntu 22.04**(本教程用 Debian 12)。
5. **Plan(套餐)**:选最低档 **1 vCPU / 1 GB RAM(约 $5–6/月)** 就够个人用。
6. **Auth(认证)**:用默认的**密码方式**即可(小白省事),系统会生成 root 密码。
7. 拉到底点 **Deploy Now**。等 2–3 分钟,状态变 **Running**。

### 1.4 记下三样东西
部署好后,点进这台服务器详情页,记下:
- **IP Address**(公网 IP,形如 `123.45.67.89`)
- **Username**:`root`
- **Password**(点眼睛图标显示)

> 💡 **先测 IP 纯净度**:把这个 IP **手动粘贴**到 `https://ippure.com/` 的查询框,看 IPPure 系数(查的是你粘进去的 VPS IP,本机用普通网络即可)。脏了(系数很高)就**删机重建**换一个 IP——Vultr 删了重建很快。
> 注意:Vultr 这类 VPS 在 ipinfo 里大概率会显示 `is_hosting=true`,这是机房 IP 的正常表现,不是单项失败。重点看是否被标记为 `vpn/proxy/tor/relay`、欺诈分是否高、Cloudflare 是否频繁验证码。

## 2. 第二步:SSH 登录到 VPS

### Windows 用户
Win10/11 自带 SSH。按 `Win 键`,输入 **`PowerShell`** 或 **`Terminal`**,打开后输入(把 IP 换成你的):
```bash
ssh root@123.45.67.89
```
- 第一次连会问 `Are you sure you want to continue connecting (yes/no)?`,输入 **`yes`** 回车。
- 然后提示 `password:`,**粘贴你的 root 密码**(注意:Linux 里输密码屏幕**不显示任何字符**,这是正常的,粘完直接回车)。
- 看到 `root@vultr:~#` 开头的提示符 = 登录成功。

### Mac 用户
打开**「终端」**(访达 → 应用程序 → 实用工具 → 终端),同样敲 `ssh root@你的IP`,流程一致。

## 3. 第三步:一条命令装 3X-UI 面板

登录 VPS 后,**复制粘贴**这条命令回车:
```bash
bash <(curl -Ls https://raw.githubusercontent.com/mhsanaei/3x-ui/master/install.sh)
```

安装过程中可能问你几个问题:
- `Would you like to customize the Panel settings? [y/n]`:输 **`y`** 自定义更安全(也可输 `n` 用默认,装完再改)。
- 若选 y,会让你设:**用户名 / 密码 / 面板端口 / 访问路径**。
  - 用户名密码:**设成你自己记得住的复杂值**(别用 admin/admin)。
  - 面板端口:可填 `2053` 之类。
  - 访问路径(Path):填一段随机字符如 `mypanel8k3`(相当于后台的"暗门",防扫描)。

装完屏幕会打印**面板访问地址、用户名、密码**,形如:
```
Access URL: http://123.45.67.89:2053/mypanel8k3
Username: xxxx
Password: xxxx
```
**把这三行复制保存好。**

> 之后任何时候,在 VPS 上敲 **`x-ui`** 回车,会出现一个菜单,可以查看面板信息、重启、改设置等。

## 4. 第四步:安全打开面板登录

面板默认是普通 HTTP,不要长期暴露在公网。最稳妥的新手做法是用 **SSH 隧道**临时打开:

1. 在自己电脑新开一个 PowerShell / Terminal 窗口,输入(把 IP 和端口换成你的):
   ```bash
   ssh -L 2053:127.0.0.1:2053 root@123.45.67.89
   ```
2. 保持这个 SSH 窗口别关,在浏览器打开:
   ```text
   http://127.0.0.1:2053/mypanel8k3
   ```
   路径换成安装时打印的随机访问路径。
3. 输入用户名密码登录。
4. 进去先把语言切中文:面板右上角通常能选 **简体中文**。

> ⚠️ 不推荐直接公网访问 `http://服务器IP:面板端口/路径`,因为登录凭据会经过明文 HTTP,面板端口也容易被扫描。只有你明确知道风险时,才临时放行面板端口;更稳妥的做法是在 VPS 防火墙里只允许自己的公网 IP 访问该端口。

### 4.1 放行代理端口

VLESS+REALITY 后面会用 `443/tcp`,需要在 VPS 防火墙放行:
```bash
apt update
apt install -y ufw
ufw allow OpenSSH
ufw allow 443/tcp
ufw enable
```

Vultr 后台若开了 **Firewall Group**,也要去后台放行 `22/tcp` 和 `443/tcp`。面板端口 `2053/tcp` 默认不需要放行,因为上面用 SSH 隧道访问。

## 5. 第五步:生成 VLESS + REALITY 节点(核心)

在面板里:

1. 左侧点 **入站列表(Inbounds)** → 点 **添加入站(Add Inbound)**。
2. 按下面填:

   | 字段 | 填什么 | 说明 |
   |------|--------|------|
   | **备注(Remark)** | 随便,如 `my-jp` | 节点名字 |
   | **协议(Protocol)** | 选 **`vless`** | |
   | **端口(Port)** | 填 **`443`** | 伪装成 HTTPS,最不显眼 |
   | **安全(Security)** | 选 **`reality`** | 关键!选了会展开下面的 Reality 设置 |

3. 在展开的 **Reality 设置**里:
   - **Dest / 目标网站**:填一个真实大站,如 **`www.microsoft.com:443`** 或 `www.yahoo.com:443`(伪装目标,要选国内能正常访问、证书正常、和你机房地区相符的大站)。
   - **SNI / Server Names**:填上面域名(不带端口),如 **`www.microsoft.com`**。
   - **公钥/私钥(Public/Private Key)**:点旁边的 **「Get New Cert」/「生成」按钮**,自动生成一对密钥(别手填)。
   - **Short Ids**:点 **生成/随机** 按钮自动填。
4. 面板通常会**自动建一个客户端(Client)并分配 UUID**;若没有,点该入站的 **添加客户端**,**Email/备注**随便填,UUID 点生成。
   - **Flow(流控)**:VLESS+REALITY 走 TCP 时,客户端这一项选 **`xtls-rprx-vision`**(性能更好、更抗探测)。**务必确保服务端与客户端这一项一致**——两端不一致会握手失败。新版面板可能已自动填好,可在下一步的分享链接里检查是否带 `flow=xtls-rprx-vision`。
5. 点 **保存(Save / 创建)**。

> REALITY 目标站不要随便填。Xray 对鉴权失败的 REALITY 请求会回落转发到目标站;如果目标站选得不合适,尤其是免费 CDN 站点,你的 VPS 可能被扫描后偷跑流量。优先选稳定可达、证书正常、同地区或同 ASN 更接近的目标;有条件可在 VPS 上用 `xray tls ping 域名:443` 检查。

## 6. 第六步:导出节点链接到客户端

1. 回到 **入站列表**,找到刚建的那条。
2. 点它右侧的 **操作(Actions)** 或展开,会看到 **二维码** 和 **分享链接(vless://... 开头的一长串)**。
3. **复制那串 `vless://...` 链接**(手机就直接扫二维码)。

### 在客户端导入

| 系统 | 推荐客户端 | 导入方式 |
|------|-----------|---------|
| **Windows** | **v2rayN** / NekoBox | 复制 `vless://` 链接 → 软件里 **「从剪贴板导入」** |
| **Mac** | **V2rayU** / NekoRay | 同上,从剪贴板导入 |
| **iPhone** | **Shadowrocket(小火箭)** / Stash | 扫二维码,或复制链接后 App 会提示导入 |
| **Android** | **v2rayNG** / NekoBox | 右上角 `+` → 从剪贴板导入 / 扫码 |

导入后:
1. 选中该节点 → 测延迟(Ping)能出数字 = 通。
2. 打开**系统代理 / 全局模式**开关。
3. 浏览器访问 `google.com` 能开 = **成功翻墙!** 🎉

## 7. 第七步:搭好后自检(接上纯净度文档)

节点能用 ≠ 节点优质。连上你新节点后,按配套文档跑一遍:
- **IPPure**(`https://ippure.com/`):IPPure 系数 `<25` 优、Cloudflare 系数 `<40` 理想、`<70` 可用需实测。
- **Scamalytics**:Fraud Score `<40`。
- **BrowserLeaks**:WebRTC / DNS / IPv6 **不漏真实 IP**。
- **Whoer**:匿名度 `>90%`。

> 详见 `docs/notes/2026-06-24-vpn节点纯净度检测指南.md`。自建 IP 是独享的,滥用历史通常比机场共享 IP 更可控;但它多半仍是机房 IP,不是住宅 IP。

## 8. 进阶可选:提速(开 BBR)

让 VPS 网络更顺(尤其晚高峰),在 VPS 上执行:
```bash
cat >/etc/sysctl.d/99-bbr.conf <<'EOF'
net.core.default_qdisc=fq
net.ipv4.tcp_congestion_control=bbr
EOF
sysctl --system
```
验证(出现 `bbr` 即成功):
```bash
sysctl net.ipv4.tcp_congestion_control
```

## 9. 常见问题排查

| 现象 | 可能原因 | 解决 |
|------|---------|------|
| 面板打不开 | SSH 隧道没保持连接 / 面板服务没启动 / 端口填错 | 保持 §4 的 SSH 窗口别关;在 VPS 上运行 `x-ui` 查看面板端口和状态 |
| 客户端连不上、延迟超时 | 端口没放行 / 节点参数错 | VPS 放行 443:`ufw allow 443/tcp`;核对客户端链接是否和面板一致 |
| 用了几天突然全断 | **IP 被墙(GFW 封 IP)** | 换协议端口先试;无效则 **Vultr 删机重建换 IP**,REALITY 也救不了被封的 IP |
| 能连但 Cloudflare 站老弹验证码 | IP 风险偏高 | 测 IPPure CF 系数,过高就换 IP |
| 速度慢、晚高峰卡 | 线路拥堵 | 开 BBR(§8);换机房;考虑 Hysteria2 协议(UDP,抗丢包好) |

## 10. 极端封锁备用方案:DNS 隧道(MasterDnsVPN)

前面的 VLESS+REALITY 是**日常主力**,但它有个前提:**国际网络是通的,只是常规代理端口被墙**。遇到下面这些**端口级封锁**场景它也连不上,需要一个"保命备用通道":

- **受限 WiFi**:酒店 / 校园 / 公司网只放行 **DNS(53 端口)**,其它全堵。
- **重大活动期间严打**:443 等常规协议端口被大面积封锁,**唯独 DNS 还放行**。

这些场景的共同点:**国际链路本身是通的,只是除 DNS 外的端口被封**。**DNS 隧道**就钻这个缝——把流量切碎塞进 DNS 查询/响应里,经公共 resolver 转发到你境外 VPS 的权威服务器穿出去。`MasterDnsVPN`(`vendor/MasterDnsVPN`,Go 实现)就是这类工具里抗封锁很强的一个。

> ❗ **它救不了"物理断网"**:DNS 隧道依赖国际链路本身是通的(查询要能转发到你的境外 VPS)。若遇到伊朗式**全国级物理断网**(国际带宽被整体切断),53 端口的 DNS 一样出不去,**此方案也无效**——那种极端情况没有纯软件解法。DNS 隧道解决的是"**端口被封**",不是"**线断了**"。

### 它和 REALITY 的定位区别

| | VLESS+REALITY(主力) | MasterDnsVPN(备用) |
|---|---|---|
| 原理 | 伪装成 HTTPS/TLS 流量(443) | DNS 隧道(53 端口) |
| 速度 | **接近原生**,能看 4K | **极慢**,只够刷文字/收发消息救急 |
| 前提 | 国际网通、只是被墙 | **哪怕只剩 DNS 能用**也能连 |
| 搭建 | 一台 VPS + 3X-UI,不需要域名 | **需要域名 + NS 委托到 VPS 上的权威 DNS**,配置更繁琐 |
| 用途 | 99% 日常 | 极端封锁时的逃生口 |

### 何时启用 / 怎么准备

- **平时不用它**,把它当"网络黑天鹅"时的应急方案。
- **前置条件(比 REALITY 门槛高)**:
  1. 你要有一个**自己的域名**(在域名商买,如 Cloudflare/Namecheap)。
  2. 在域名 DNS 设置里先建一个 **A 记录**:`ns.yourdomain.com -> 你的 VPS IP`。
  3. 再建一个 **NS 记录**:`t.yourdomain.com -> ns.yourdomain.com`。NS 记录指向的是权威服务器名字,不是直接填 VPS IP;这样公共 resolver(8.8.8.8 等)才会把 `t.yourdomain.com` 的查询转发到你 VPS。
  4. VPS 防火墙放行 `53/udp`;如果 53 端口被 `systemd-resolved` 等服务占用,需要先处理端口占用。
  5. VPS 上跑 `server_linux_install.sh` 装服务端,安装时域名填委托子域 `t.yourdomain.com`;客户端用 `client_config.toml` 指向这个域名。
- **建议做法**:和 REALITY **共用同一台 VPS**,DNS 隧道服务端平时开着但客户端不连;一旦主力失联,切到 DNS 隧道续命。

> ⚠️ DNS 隧道流量在 DNS 监控下其实**特征明显**,长期大流量使用容易被针对。它的价值在"**极端环境下还能连**",不是"隐蔽",也不是"快"。别拿它当日常。具体参数(多 resolver、分片、负载均衡 8 种模式等)见 `vendor/MasterDnsVPN/README.MD`。

## 11. 一句话总结

> 租东京 1G VPS → SSH 登录 → 一条命令装 3X-UI → 面板里点出 VLESS+REALITY(端口 443、伪装 microsoft) → 复制 `vless://` 链接进 v2rayN/小火箭 → 开全局能开 Google → IPPure 自检纯净度。被封就删机换 IP。
