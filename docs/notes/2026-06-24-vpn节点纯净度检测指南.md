# VPN / 代理节点纯净度检测指南

> 怎么判断买的 VPN / 机场节点好不好——不要被单一分数误导,多站交叉验证 + 测速 + 泄露检测 + 解锁实测,五项都过才算好节点。
>
> 创建日期:2026-06-24

---

## 0. 先纠正一个方向问题(很重要)

IPPure 页面上的表盘是**风险刻度,不是纯净度刻度**:

- **左绿 → 右红,数字越低越好**(0 最干净,100 最危险)。
- 截图里的 `31% 中性`、`63% 中度风险` 都是"风险值",所以 31 比 63 好。
- 官方对 **Cloudflare 系数** 的定义已证实这点:
  `Cloudflare 系数 = 100 − Cloudflare Bot Score`,Bot Score 越高越像真人越安全,所以换算后的系数**越低越好**,与 IPPure 风险系数方向一致。

> 一句话:这页所有表盘,**越靠左(数字越小)= 越好**。

---

## 1. 为什么不能只看一个分数

1. **商用节点是共享 IP**,纯净度随时间、随同节点其他用户的行为波动。某一刻的好分数不代表稳定。
2. **不同检测站口径不同**:有的看"是否被标记为代理",有的看"欺诈数据库命中",有的看"Cloudflare 人机识别"。单一来源会有偏差。
3. **纯净度高 ≠ 服务好**。一个 IP 很干净,但延迟高、晚高峰掉速、有 DNS/WebRTC 泄露、解锁不了目标站,照样不能用。

所以要分三层验证:**① IP 风险纯净度 → ② 泄露 / 匿名度 → ③ 速度 / 解锁实测**。

---

## 2. 第一层:IP 风险 / 纯净度(多站交叉)

逐个节点连上后,在以下站点查**当前出口 IP**,横向对比。

### 2.1 IPPure(中文,主测)— https://ippure.com/

| 指标 | 方向 | 判断标准 |
|------|------|---------|
| **IPPure 系数** | 越低越好 | 理想 `<25`;`25–40` 中性可用;`>50` 偏脏 |
| **Cloudflare 系数** | 越低越好 | 理想 `<40`;`>60` 访问 CF 盾站会频繁弹验证码 |
| **IP 类型** | — | 住宅(Residential)最佳;机房 / IDC / Datacenter 风控高 |
| **VPN 溯源 / 浏览器指纹** | — | 能溯源出 VPN、指纹不一致都是减分项 |

> 表盘色带(据截图刻度):约 `0–15` 深绿、`15–40` 绿/中性、`40–50` 黄、`50–70` 橙、`70–100` 红。
> 注意:Cloudflare 系数不只跟 IP 有关,还跟**浏览器行为、最近的验证码结果、JS 检测**有关,换浏览器/清环境再测会变。

### 2.2 ipinfo.io(查 IP 本质)— https://ipinfo.io/

实测页面会给出这些字段,用来判断 IP 的"出身":

- **ASN / Organization**:看归属哪个网络。是 `Amazon / Google / OVH / DigitalOcean / Hetzner` 这类机房 ASN,基本就是数据中心 IP,天然风控高。
- **Privacy 检测布尔值**:`is_vpn` / `is_proxy` / `is_tor` / `is_relay` / `is_hosting` / `is_mobile`。
  - 好节点:这些尽量都是 `false`,尤其 `is_hosting=false`。
  - 出现 `is_vpn=true` 或 `is_hosting=true`,说明已被识别。
- **Company type**:`isp`(住宅宽带)> `business` > `hosting`(机房,最差)。
- **Geolocation**:归属地要和节点宣称地区一致,不一致说明 IP 库混乱或落地飘。

### 2.3 Scamalytics(欺诈风险分)— https://scamalytics.com/

实测评分口径(0–100,**越低越好**):

| Fraud Score | 等级 | 含义 |
|-------------|------|------|
| `0–40` | Low Risk | 可信,放行 |
| `41–70` | Medium Risk | 监控 / 要求验证 |
| `71–100` | High Risk | 大概率被拦 / 挑战 |

它综合了地理位置、代理/VPN 检测、黑名单、机器学习模型。**目标节点选 `<40`。**

---

## 3. 第二层:泄露与匿名度(暴露真实 IP 才是大事)

纯净度再高,如果泄露了真实 IP,翻墙就是裸奔。

### 3.1 BrowserLeaks(泄露专测)— https://browserleaks.com/

实测它提供这些检测项,重点看前三个:

- **WebRTC Leak**(最关键):WebRTC 会绕过 VPN 隧道,通过 STUN 服务器暴露你的**真实公网/内网 IP**。这里若显示出你家宽带 IP = 泄露,必须关掉或屏蔽 WebRTC。
- **DNS Leak**:DNS 请求若走了你本地 ISP 的服务器(而不是 VPN 隧道),= 泄露。应只看到 VPN 提供的 DNS。
- **IP Address**:看 IPv4 / **IPv6 是否双重暴露**(很多 VPN 只代理 v4,v6 直连漏真实地址)。
- 其余:Canvas / WebGL / Font / TLS-QUIC 指纹——用于浏览器指纹追踪,做匿名要求高时再看。

**标准:WebRTC / DNS / IPv6 三项都不能出现你的真实 IP 或真实 ISP。**

### 3.2 Whoer.net(综合匿名度%)— https://whoer.net/

实测评分口径:**匿名度百分比,越高越好,100% 最佳**。

- 100% = 没有任何泄露,且**所有参数一致**(时区、浏览器语言、DNS、系统设置不互相矛盾)。
- 扣分来源:检测到真实 ISP 的 DNS、WebRTC 泄露、时区/语言与 IP 归属地不匹配。
- **标准:目标 `>90%`**;低于这个值点开看它标红的具体项去修。

---

## 4. 第三层:速度与解锁(能不能真用)

| 测什么 | 工具 | 标准 |
|--------|------|------|
| **延迟 / 下载速度** | fast.com、speedtest.net | 晚高峰(20:00–23:00)再测一次,看掉不掉速 |
| **解锁流媒体** | 直接打开 Netflix / YouTube / Disney+ | 能正常播放、无"代理检测"报错 |
| **解锁 AI/CF 盾站** | 打开 ChatGPT / Claude / 各类 CF 防护站 | 不频繁弹人机验证(呼应 §2.1 的 CF 系数) |
| **稳定性** | 挂着用 1–2 小时 | 不频繁掉线、不无故切 IP |

---

## 5. 判断标准速查(一个节点"好"的门槛)

| 维度 | 指标 | 合格线 |
|------|------|--------|
| IP 风险 | IPPure 系数 | `<25` 优 / `<40` 可用 |
| IP 风险 | Cloudflare 系数 | `<40` |
| IP 风险 | Scamalytics Fraud | `<40` |
| IP 本质 | ipinfo `is_hosting` | `false`(住宅 IP 最佳) |
| 泄露 | WebRTC / DNS / IPv6 | 不暴露真实 IP/ISP |
| 匿名度 | Whoer | `>90%` |
| 速度 | 晚高峰下载 | 满足你的用途(看 4K 需 ≥25Mbps) |
| 解锁 | 目标服务 | 能播 / 不频繁验证码 |

> **判断流程:** 连节点 → IPPure 看风险(低 + 住宅 IP + 无 proxy 标记)→ Scamalytics/ipinfo 交叉验证 → BrowserLeaks 查泄露 → Whoer 看匿名度 → speedtest 测速 → 试解锁目标站。**八项都过,才算好节点。**

> 填表小贴士:`↓` 标的列越小越好;`is_hosting` 填 真/假;`WebRTC泄露` 填 有/无;选**风险列都低 + 无泄露 + 能解锁**的那行。
> 如果**所有节点 CF 系数都偏高**,说明这家机场多用机房 IP,遇 Cloudflare 盾就难受——这是选服务时的真实短板,要稳过 CF 得找住宅 IP(Residential)节点,但通常更贵/更慢。
