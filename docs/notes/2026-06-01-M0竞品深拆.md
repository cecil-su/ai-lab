# M0 · 竞品深拆与 H1 差异化空间

> 目的：回答 H1——在**阅文作家助手免费且内置 AI** 的前提下，独立/开源工具的差异化空间在哪？
> 调研日期：2026-06-01（后台研究 agent + 人工校读）。
> **事实纪律**（项目硬规则）：一手来源优先；二手总结只作线索；绝对化数字标"存疑"；拿不准标"未证实"。本文严格保留这些标注，**不拔高结论**。

---

## 一、竞品速览

| 竞品 | 定位 | 开源 | 自定义 LLM | 长篇一致性 | 活跃度 | 来源强度 |
|---|---|---|---|---|---|---|
| **阅文作家助手 + DeepSeek-R1** | 片段辅助 + 发布工具 | 否 | 否（绑定自有模型） | 片段级，有限 | 持续更新 | 中（官方公告+媒体，部分存疑） |
| **NovelForge** | 结构化长篇创作 | 是（限商用） | 是 | 知识图谱+Schema | 活跃（886★，2026-05） | 强（GitHub README 一手） |
| **AI_NovelGenerator** | 全自动长篇生成 | 是 | 是 | 向量检索+状态追踪 | 低（重构中） | 强（README 一手，5.2k★） |
| **Long-Novel-GPT** | 批量扩写 | 是 | 是 | RAG+大纲层级 | 低（1.1k★） | 强（README 一手） |
| **星月写作 / 马良写作**（商业） | 网文全链路 SaaS | 否 | 否 | 知识图谱（存疑） | 商业运营 | 弱（营销材料，数字存疑） |

> 关键观察：**开源三件套（NovelForge/AI_NovelGenerator/Long-Novel-GPT）的整书一致性方案，反而比阅文作家助手更系统**——阅文强在"片段辅助 + 发布闭环"，弱在"整书级结构管理"。

---

## 二、阅文作家助手的能力与短板（最大竞品）

**四大 AI 功能**（官方公告，可信）：智能问答 / 描写润色 / 提取(大纲+角色) / 画师(文生图)。妙笔 2023-07 上线，DeepSeek-R1 2025-02 集成（网文领域首家）。

**短板（有用户引语支撑）**：
- 网文作家"咸鱼军头"：*"AI 词汇量更大、场景丰富，但无法把控网文的节奏、读者的爽点。"*（[知乎汇总](https://www.zhihu.com/question/11928857969)）
- R1 版输出冗长（400 字要求给 1000 字）、形容词堆砌、"人味"不足。
- 功能均为**片段级辅助**，未见整书级自动长篇生成与跨章一致性系统（**存疑**：可能有但未公开演示）。

**未证实的信息缺口**（需人工实测）：
1. 非阅文签约作者的 AI 功能配额是否受限。
2. 是否在开发整书一致性功能。
3. 一键发布仅对接阅文系平台（起点/QQ阅读/创世）——番茄/七猫/晋江作者享受不到闭环。

## 三、H1 差异化空间结论（逐条标强度）

| # | 差异化候选 | 证据 | 强度 |
|---|---|---|---|
| 1 | **支持自定义/本地 LLM** | 阅文绑定自有模型不可替换；开源三件套均支持 OpenAI 兼容接口、可接本地 Ollama | **强** |
| 2 | **整书级结构管理 + 一致性系统** | 阅文四功能均片段级；开源工具有知识图谱/向量检索/状态追踪 | **中**（阅文完整边界未一手核实） |
| 3 | **跨平台发布自由** | 阅文一键发布仅对接阅文系；多平台投稿作者有缺口 | **中**（AI 配额差异属存疑） |

**反向警示（不支撑差异化，别踩）**：
- ❌ "阅文 AI 质量差"——那是通用 LLM 特性，独立工具调同款模型会遇同样问题。
- ❌ "开源更便宜"——阅文免费，开源要自付 API 费，成本优势不成立。
- ⚠️ 商业工具（星月/马良）已在抢"专业网文工具"定位，独立工具差异化需靠**技术透明 / 数据主权 / 本地化 / 跨平台**，而非泛泛"更专业"。

## 四、对项目的含义（衔接已有判断）

- **找到了 ≥2 个有证据的差异化候选**（候选 1 强、候选 2/3 中）→ 按 M0 通过标准（"找到 ≥2 个阅文没解决好的真实痛点"），**M0 初步通过**，但候选 2/3 需人工实测补强。
- **差异化方向收敛**：与本仓库已建的"框架/实例分离 + 跨气质复用"六层准备包**高度契合**候选 2（整书级结构 + 一致性）——这正是阅文片段级辅助的盲区。
- **下一步人工验证清单**（补强中等强度证据）：登录阅文作家助手实测非签约配额、跟踪其整书一致性功能动向、核实星月/马良的营销数字。
